# Release Notes — 1.0.1

Visual Climate Scheduler V1.0.1 adds translated Home Assistant setup and
options screens while keeping all V1 scheduling behaviour unchanged.

## Added

- Danish (`da`)
- Dutch (`nl`)
- Finnish (`fi`)
- French (`fr`)
- German (`de`)
- Italian (`it`)
- Norwegian Bokmål (`nb`)
- Spanish (`es`)
- Swedish (`sv`)
- Automated validation that every translation catalogue has exactly the same
  keys as the English source and contains no empty values.

The custom schedule editor remains English in this release. Its frontend
localisation framework is tracked separately in `docs/I18N_ROADMAP.md`.
