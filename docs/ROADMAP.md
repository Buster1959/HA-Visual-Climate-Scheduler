# Roadmap

## Phase 0 — Definition
Project definition, UX principles, architecture and data model.

## Phase 1 — V1 Core
Integration skeleton, config flow, area/climate discovery, persistent storage, schedule engine and visual editor.

## Phase 2 — V1 Advanced
Copy/apply, overrides, startup reconciliation, validation, error handling and tests.

## Phase 3 — V1 Release
User documentation, Wiki, HACS packaging and release process.

## Phase 4 — V2 Learning
Behaviour history, pattern detection, time/temperature learning, confidence and suggestions.

## Phase 5 — V2 Refinement
Seasonal patterns, multiple learned behaviours and optional automatic learning.
