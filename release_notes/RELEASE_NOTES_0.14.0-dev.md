# 0.14.0-dev — Block 10: Copy Schedule to Rooms

- Add **Copy schedule to rooms** inside the Schedule page, avoiding a separate
  page or another schedule type.
- Select one or more destinations; the current source editor state is saved and
  copied to their seven daily schedules in one operation.
- Destination room/zone identity, Area and thermostat assignments are retained.
- Copied daily period collections are detached, while their stable period IDs
  remain logical identities.
